# 03 · Frameworks 商業框架

收錄可重複使用的思考工具與決策模型。

## 建議分類

- **策略類**:Porter 五力、SWOT、Blue Ocean、Jobs-to-be-Done
- **產品類**:Lean Canvas、Business Model Canvas、PMF
- **行銷類**:AARRR、4P / 7P、定位三角
- **財務類**:Unit Economics、LTV/CAC、損益結構
- **決策類**:Second-order thinking、Inversion、Pre-mortem
- **組織類**:OKR、RACI、SCARF

每個框架一個檔案,內容包含:
1. 框架是什麼
2. 何時用
3. 何時不要用
4. 實際案例
