# 02 · Notes 永久筆記

這裡放的是「已經想清楚」的概念,每篇筆記只談一個核心想法。

## 寫作原則 (Zettelkasten)

1. **原子化**:一篇筆記只表達一個概念
2. **自己的話**:用自己的語言重述,不是 copy-paste
3. **連結**:每篇至少連到一篇相關筆記 `[[xxx]]`
4. **來源**:標註出處(書、文章、對話)

## 模板

```markdown
# 概念名稱

**標籤**: #商業模式 #定價

## 核心想法
(一句話講清楚這個概念)

## 為什麼重要
(這對商業判斷的意義)

## 相關概念
- [[概念A]]
- [[概念B]]

## 來源
- 書/文章/作者
```
