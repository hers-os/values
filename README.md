# 數據大腦 (Data Brain)

> 個人第二大腦 · 商業思維知識庫

這是我用來累積、整理、連結商業思維的個人知識管理系統。
靈感來自 PARA 方法 (Tiago Forte) 與 Zettelkasten。

## 核心目的

- **累積**:把日常閱讀、觀察、實戰經驗轉成可檢索的筆記
- **連結**:讓不同領域的概念互相碰撞,形成新的洞見
- **輸出**:把累積的思考轉化為決策、文章、產品

## 目錄結構

```
.
├── 01-inbox/          # 收件匣:臨時筆記、待整理素材
├── 02-notes/          # 永久筆記:已整理過的核心概念 (Zettel)
├── 03-frameworks/     # 商業框架:模型、方法論、決策工具
├── 04-cases/          # 案例研究:公司、產品、市場事件
├── 05-projects/       # 進行中的專案與目標
├── 06-resources/      # 資源庫:書摘、文章、課程筆記
└── 07-archive/        # 封存:已完成或不再活躍的內容
```

## 命名規範

- 筆記檔名:`YYYY-MM-DD-簡短主題.md`
- 永久筆記可使用:`概念名稱.md`(便於 wiki 連結)
- 內部連結使用:`[[筆記名稱]]`

## 工作流

1. **捕捉** → 把任何想法/閱讀丟進 `01-inbox/`
2. **整理** → 每週把 inbox 的內容萃取成 `02-notes/` 的永久筆記
3. **連結** → 在永久筆記中加上相關概念的 `[[連結]]`
4. **應用** → 從筆記庫中組合出 `05-projects/` 的具體產出
