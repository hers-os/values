# 06 · Resources 資源庫

長期參考用的資料:書摘、文章筆記、課程、Podcast。

## 子分類建議

```
06-resources/
├── books/         # 書摘
├── articles/      # 文章筆記
├── courses/       # 課程筆記
├── podcasts/      # Podcast 重點
└── people/        # 值得追蹤的人 + 他們的核心觀點
```
